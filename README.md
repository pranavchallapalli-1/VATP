# VATP
Verilog Agentic Tool project 

LangGraph based verilog code generation using ollama for qwen-2.5-coder-7B model for code generation.

-------------------------
Environment :

1) Python:3.10.20
2) icarus verilog:13.0 (sudo apt update && sudo apt install iverilog gtkwave)
3) yosys: 0.62+112 (https://github.com/yosyshq/yosys)
4) cryptominisat:5.16.0 (https://github.com/msoos/cryptominisat)
5) opensta:2.7.0 (https://github.com/the-openroad-project/opensta)
